# Jenkins Basic CI Project

## Overview

This project demonstrates a basic Jenkins Continuous Integration (CI) workflow by connecting Jenkins with a GitHub repository.

Jenkins pulls the source code from GitHub, executes a basic build command, displays the console output, and reports the build status.

## Objective

The objective of this project is to understand how Jenkins integrates with GitHub and performs a basic CI build.

## Tools Used

- Jenkins
- GitHub
- Git
- Linux
- Bash
